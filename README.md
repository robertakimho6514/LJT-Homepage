# Junteng Liu — Academic Homepage

This repository contains the source for Junteng Liu's personal academic homepage, built from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

The site includes research interests, education, research experience, publications, skills, and contact information.

## Local development

Follow the Academic Pages documentation or run the site with Jekyll/Bundler. The configured project-site base URL is `/LJT-Homepage`.
